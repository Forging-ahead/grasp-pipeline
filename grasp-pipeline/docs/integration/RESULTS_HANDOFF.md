# 成绩统计和接入交付

## 每次实验必须可追溯

以一个明确的代码、配置、权重和资产版本运行任务清单。每条记录标记 benchmark/task、实际 seed/初态、观测模式、机器人、动作规格、实际规划/控制后端、目标定义及预算。不同版本的历史成功不能合并成同版结果；诊断重试与正式 trial 分开。

初始 reset 不同于阶段切换。一个完整任务必须在同一物理回合中执行，不通过中途改物体位置、改原目标或重置成更容易状态来完成。

## 分开统计这些结果

| 指标 | 判定方式 | 不能代表什么 |
| --- | --- | --- |
| 接口检查通过 | 数据结构、来源、模型/动作/状态等静态检查通过 | 不证明可达、无碰撞或任务成功 |
| 有规划记录 | 发生了候选/路径/预检尝试，即使动作数为 0 | 不代表已经物理尝试抓取 |
| 有物理执行 | 实际 actions_executed > 0 | 不代表抓稳或完成任务 |
| 抓取成功 | 有真实闭合、接触和抬升等规定证据 | 不代表搬运/放置或原生任务成功 |
| 原生任务成功 | 本环境原生成功判定为 true | 可能出现管线尚未完整结束、顺序不符等情况 |
| 完整管线成功 | pipeline_complete、native_success 为真且动作数 > 0 | 仍需独立检查指令顺序和训练质量 |
| 候选成功轨迹 | 完整成功且排除已知指令顺序错误 | 未审核或缺完整观测时，不自动成为合格 SFT 数据 |

任务覆盖目标建议报告“同一版本在固定任务清单中，多少个不同任务至少得到一条成功轨迹”。同时列出每任务初态数、trial 数和成功次数。重复跑多个初态后取最好结果，与单初态单次试验不是同一成功率口径。

正式表格至少列 configured tasks、支持/未支持任务、产生规划记录任务、发生物理执行任务、native true、完整成功、顺序合格数，以及技术错误和超时。保留总体分母，另给支持子集成绩时同时说明子集选择。未支持技能不应被写成模型尝试后失败，也不能从总表中消失。

如果需要官方分数，由接入方使用所选 benchmark 版本的原评估流程、观测条件、初态和预算单独验证；本项目的工程采集结果不直接等同于标准视觉策略分数。

## 必须保留的交付物

- 环境/包装层/本管线版本、配置、模型和资产指纹，以及实际启动命令。
- 任务清单和每个 trial 的 seed/初态、原目标、最终状态、原生结果、管线状态、步数、耗时、退出原因。
- 实际输入点云、来源、采集序号、目标区域、场景/机器人模型和规划诊断，资源 URI 可解析且摘要可核对。
- 连续状态/动作/阶段、视频、预检和控制日志；失败也保存已有部分，说明没录到视频或没有动作的原因。
- 指令顺序与数据质量审核；如用于 VLM SFT，保存动作前观测和真实决策/工具参数，不把 code policy 标签改名为 VLM 决策。
- G0–G8 验收记录、已知限制、未实现任务、实际后端以及最小复现方式。

## 用于 VLM 监督数据时的额外记录

| 时刻 | 至少保留什么 | 标签含义 |
| --- | --- | --- |
| 发起技能前 | 当时可用的 RGB/深度/状态、任务和历史，采集序号与来源 | 模型真正能看到的输入，不能用未来图像或释放后的状态作输入 |
| 形成决策时 | 技能/工具名、目标实体、目标 TCP 位姿或关节目标、坐标系、夹爪命令及其他参数 | 教师实际请求的目标；如由 code policy 给出，标记 code_policy |
| 执行之后 | 实测轨迹与关键点、误差、接触/抓取证据、原生结果和失败 | 执行结果；它不自动等于当时请求的目标参数 |

实测末端关键点、规划终点和工具调用参数需要分别保存。当前旧记录的阶段关键点主要是动作后的实测位姿，没有逐步完整原始观测或 VLM 决策；仅导出这些坐标，不能声称已得到完整的“obs＋VLM 工具选择”训练集。

## 最终交接清单

- [ ] 设计单内 benchmark/机器人/观测/规划/动作和成功判定已确定，所有待定项有说明。
- [ ] 九类方法职责有人实现，调用链确实使用它们，配置和入口能复现。
- [ ] 真实资源与坐标、FK、碰撞、预演恢复和夹爪语义已验证。
- [ ] 至少一个完整任务在连续回合中有视频与原生判定；失败和预算退出可复现。
- [ ] 本环境的关节/复合技能按实际范围声明，不把单臂抓放等同于全部任务支持。
- [ ] 结果分母、版本和试验次数完整，没有历史成功并集或其他 VLA 的未标注代跑。
- [ ] 文档、入口、参数和验收证据一起交付，接收者知道哪些能力仍未实现。

当前历史 v10 的 88/86/85 三个数字仅属于 LIBERO 原固定初态实验。它们可作为结果解释的例子，不能迁移成新 benchmark 的成绩。本轮第四阶段只交付文档和示例，没有新环境实验成绩。
