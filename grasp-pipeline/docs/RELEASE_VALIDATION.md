## 历史 v10 的统计口径

历史 130 个任务各运行一次，`seed=0`、官方初态索引 0，保存每任务视频。不同口径为：

- 88 / 130：原生最终目标判定为真。
- 86 / 130：管线完整成功、原生最终目标为真且实际执行了动作。
- 85 / 130：在上一口径中再排除一个已知指令顺序问题，作为候选轨迹数量。

已知顺序问题是 `libero_90_LIVING_ROOM_SCENE4_stack_the_left_bowl_on_the_right_bowl_and_place_them_in_the_tray`：最终目标成立，但动作顺序与指令不一致。85 条也只是候选数据，不代表已经具备完整的 VLM SFT 观测与决策标签。

这些是 teacher 条件下的 code policy 结果：使用仿真目标信息、掩码/位姿/碰撞几何，并非仅 RGB 的 VLA 基准成绩。原视频与完整结果仍在原交付目录，本源码包不重新分发视频，不将不同历史版本的成功合并。
