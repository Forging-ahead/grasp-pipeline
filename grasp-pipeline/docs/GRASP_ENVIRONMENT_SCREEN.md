# 抓取端点环境筛选与机构位姿迭代

本次从 `libero` 的 `4d71d11`（actor 基线 `6d8cd7d`）继续开发。冻结的 130 项旧结果仍单独保留，不用本轮部分任务的成功替换旧结果。

## 刚体抓取：评分排序与碰撞可行性分开

GraspGen 仍只接收目标物体点云，预训练生成器、判别器及 200 候选配置没有改变。模型评分不是包含当前场景障碍物、机械臂可达性和后续放置的完整成功概率。

原流程已经按评分顺序尝试多个候选。新增步骤位于实际张开夹爪之后、逐候选调用规划之前：

1. 读取真实夹爪碰撞几何相对当前控制点的变换，以及当前测得的开口宽度。
2. 在独立 `MjData` 中将夹爪几何放到每个候选末端位姿。
3. 用 `mj_geomDistance` 检查物理碰撞几何，包含桌面、邻物、容器及目标物体的掌部接触。
4. 剔除阻挡候选，保留其余候选的原模型分数和顺序，再执行原来的全臂规划、接近/进入路径、实际几何及双指接触检查。

默认最小间距为 0 米，距离不大于 0 加数值保护量 `1e-7` 米即拒绝。没有增加碰撞豁免；最终夹持位置的手指与目标接触沿用既有权限，手掌仍检查目标碰撞。视觉几何不会冒充碰撞几何，原接触位掩码及显式接触对也参与筛选。

这一阶段只检查张开夹爪的终点，不求解 IK，不改变真实环境积分状态、控制目标或回合计数。通过后仍可能因手臂不可达或接近路径碰撞而失败。若所有候选均被筛掉，明确记录 `grasp_environment_collision`，不记作已经夹取但没夹住。

`grasp_environment_screen=False` 可在程序配置中关闭该步骤，`grasp_environment_clearance_m` 可配置为 0 至 0.01 米。默认不设置模型分数的绝对阈值，因为不同物体的分数尚未做成功率校准。本轮未加入 GraspGen 候选去重/多样性重排，未加入闭爪后抬升或整段搬运的候选预检。

逐阶段的 `GRASP_ENVIRONMENT_SCREEN.json` 保存每个输入候选的原生成编号、筛选前排序、模型分数、阻挡部件、距离与见证点；`environment_candidates.json` 保存通过列表。`screened_candidates.json` 仍是环境筛选之前的朝向及目标接近程度筛选结果。

## 机构操作：从实际失败状态验证规则

抽屉和门不调用 GraspGen。把手位置、方向、滑动轴/铰链轴仍来自仿真模型，位姿由共享几何规则计算；实际开关由物理接触完成。

- 原来的中心夹持、0°/35°/55°及翻转候选保留在最前面，原宽度准备方式保留。
- 补充共享倾角及把手中间半段内的夹持位置。额外候选先做端点环境筛选，手指接触权限缩小到识别出的把手几何，不扩大到整个柜体。
- 圆柱门把手增加绕其长轴的自由度选择。仅在长轴与铰链轴平行时使用可自由绕轴的局部 IK；旋钮仍保持传递转矩所需的完整朝向约束。
- 铰链预检由把手绕轴的位置变化推算门角度；轴心附近和旋钮保留旋转推算方式。这样不会把“手腕朝向没变”误认为“门没有转动”。
- 局部接近虽然成功、后续接触或整段机构运动失败时，第二轮确实尝试 cuRobo 的全局接近分支。修复前这一轮对局部接近成功的候选仍重复相同的局部解，没有尝试另一条全局关节路径。

局部 IK 的可选自由轴保留全部关节限位、真实几何接触和插值检查；执行使用实际求解出的末端朝向。目标关节区间、官方成功谓词和原始初态不改。没有增加任务名字分支或单任务世界坐标。

机构阶段另存 `HANDLE_CANDIDATES_ALL.json`、`HANDLE_ENVIRONMENT_SCREEN.json` 和实际尝试的 `HANDLE_CANDIDATES.json`。其中的分值仅表示几何搜索顺序，不是 GraspGen 预测分数。

## 验证及复用入口

`tests/test_grasp_environment.py` 使用真实 MuJoCo 几何验证遮挡、高分候选跳过、手指/手掌权限、目标以外的障碍物、旋转坐标、平面及状态隔离。`tests/test_articulation_geometry.py` 与扩展的 `tests/v10/test_cartesian.py` 检查圆柱对称性、旋钮的刚性约束、门角度推算、自由轴的限位和碰撞检查。

针对性复验可用 `tools/libero_evaluation/run_subset.py`：显式传入任务键、源码目录、路径配置、修订编号和 GPU 槽位。每项初态 0、种子 0、最多 5000 步，外层一次，保留失败与超时；运行前后核对源码，最终结果必须匹配任务、驱动和模块来源。部分任务复验不能作为新版全 130 项成功率。

有关距离查询及编译后凸碰撞几何的语义，参见 [MuJoCo 官方说明](https://mujoco.readthedocs.io/en/stable/computation/#geom-distance)。
