# GraspGen 管线代码整理计划与进度

目标是整理我们自己的 GraspGen、cuRobo 和 code policy 管线，让外部 benchmark 的维护者清楚接入时需要提供什么、修改什么、如何验证与评分。本轮暂停性能迭代，不替 RoboTwin、RoboCasa 编写或运行适配。

[在线进度页](https://chatgpt.com/space/page_4469bb3185288191a60707ef665c2f7a)与本文件记录同一计划；当前对话已在侧栏置顶。进度按实际工作更新，不启动定时任务。
